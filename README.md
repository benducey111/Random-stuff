# For Dahlia 💖

A little anniversary website — dahlia flowers, falling petals, our photos, our
song, and a live counter of how long we've been together.

## What's inside
- **index.html** — the page
- **styles.css** — the look (dahlia flowers are drawn with pure CSS)
- **script.js** — the live "together for" counter, photo gallery, music + petals

## How to use it
1. **Add your photos** → drop pictures into the `images/` folder
   (see `images/README.txt`). Missing photos show a pretty 🌺 placeholder.
2. **Add the song** → put `indigo.mp3` in the `music/` folder
   (see `music/README.txt`).
3. **Set your exact anniversary** → open `script.js` and edit `START_DATE`
   at the very top. It's currently set to **July 9, 2025, 6:15 AM** so the
   counter reads about *10 months, 25 days*. Change it to your real moment.
4. **Open it** → double-click `index.html`, or deploy the folder to Netlify
   (drag-and-drop the whole folder onto Netlify, just like before).

## Editing the photo list
The photos shown are listed at the top of `script.js` in `PHOTOS`. Add or
remove lines there to match the files in your `images/` folder.
