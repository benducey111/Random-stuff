PUT THE SONG HERE 🎵

The website plays a file named:

  indigo.mp3

To add "Indigo" by Sam Barber as the background music:
  1. Get an .mp3 of the song (one you own / have the rights to).
  2. Drop it in THIS folder and name it exactly:  indigo.mp3
  3. That's it — the "Play our song" button in the top-right will play it.

Note: phones and browsers block music from auto-starting, so the song begins
on the first tap/click anywhere on the page (or via the button). That's normal.

If your file has a different name, update the <source src="music/indigo.mp3">
line in index.html.
